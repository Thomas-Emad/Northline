This project doesn't ship its own composer.json (it's meant to be dropped
into a project created via `composer create-project laravel/laravel`).
For reference, these are the package constraints it targets:

{
    "require": {
        "php": "^8.2",
        "laravel/framework": "^12.0",
        "inertiajs/inertia-laravel": "^1.0",
        "filament/filament": "^5.0"
    }
}

Filament v5's Resource/Form/Table/Page API is unchanged from v4 (v5 mainly
adds Livewire v4 support), so no code in app/Filament needs to differ between
the two — this same code runs on either, but `composer require` should pin
"^5.0" as shown above and in README.md.
